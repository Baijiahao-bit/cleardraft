# 本次交付的验证结论

验证日期：2026-10-11。环境：Windows、Python 3.12.10。样本均由仓库脚本人工生成，没有使用用户真实文档，也没有宣称样本带有 OpenAI textGrain。

**本项目完成的是文档重建、指定字符与元数据清理。它没有实现或验证 textGrain 去除。** 对“重新打一遍同样内容是否还会被官方识别”这一问题，本次没有官方检测权限，不能给出实际检测阴性结论。官方机制表明，保留原文字词不能据此推断统计信号已经消失。

## 复跑

在项目目录的 PowerShell 执行：

```powershell
.\.venv\Scripts\python.exe scripts/verify_evidence.py evidence/sample-run
.\.venv\Scripts\python.exe scripts/generate_evidence.py --output evidence/new-run
.\.venv\Scripts\python.exe scripts/verify_evidence.py evidence/new-run
.\.venv\Scripts\python.exe -m pytest --cov=cleanroom --cov-report=term-missing --cov-fail-under=80
```

如环境尚未安装开发依赖，先运行 `python -m pip install -r requirements-dev.txt`。新样本目录必须不存在，避免覆盖证据。

## 官方机制依据

OpenAI 2026-10-05 公告把 textGrain 描述为选词中的统计信号；帮助中心明确它不插入隐藏字符。文本检测访问需获批。参见 [官方公告](https://openai.com/index/eu-text-provenance/)、[帮助中心](https://help.openai.com/en/articles/8912793-provenance-signals-in-openai-generated-content) 与 [API 文档](https://developers.openai.com/api/docs/guides/content-provenance)。这些资料是机制与能力边界的依据，不是本工具得到官方检测结果的证据。
