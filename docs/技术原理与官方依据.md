# 技术原理与官方依据

## 原样重打为什么不能证明去掉新文本水印

OpenAI 在 2026 年 10 月 5 日的官方公告介绍了 textGrain。官方说明将其描述为文本选词中的统计信号，并明确区分于隐藏字符或不可见空格。检测能力面向获批机构；本项目没有接入此类检测器。[官方公告](https://openai.com/index/eu-text-provenance/)、[来源信号 FAQ](https://help.openai.com/en/articles/8912793-provenance-signals-in-openai-generated-content)。

据此，若重新导出后仍保留相同的词语及顺序，改变文件容器、键盘输入方式或字体，不足以证明该统计信号消失。这是对原理的推论，本项目未做官方检测器的前后对比实验。

因此，“新文档没有原文件元数据”“没有四种指定不可见字符”与“没有 textGrain”必须分别说明。本项目只对自身实施的检查负责，官方水印检测状态为 `not_tested`。

## 需要区分的几类信息

| 类型 | 常见载体 | 本项目范围 |
| --- | --- | --- |
| 可见水印 | 页面中的文字、形状、图片 | 不提供通用的可见水印识别或擦除保证 |
| 不可见字符 | Unicode 文本字符 | 检查并按选项清理四种指定字符 |
| 文档元数据 | 作者、编辑软件等文档属性 | 清理当前实现支持的字段，报告可检查项目 |
| 复杂或嵌入内容 | 批注、附件、图像、公式、嵌入对象 | 识别可支持的候选风险；保留模式不承诺清空 |
| 统计文本水印 | 生成文本的选词规律 | 无检测或消除保证，原样重建不构成去除证据 |

OpenAI API 文档中另有内容来源相关说明。使用相似的“来源”“水印”术语，不意味着所有机制都是文件属性，也不意味着一个通用清理工具能验证全部机制。[Content provenance 文档](https://developers.openai.com/api/docs/guides/content-provenance)。

## 字符处理范围

| 字符 | 常见名称 | 默认处理 |
| --- | --- | --- |
| `U+200B` | ZERO WIDTH SPACE，零宽空格 | 在受支持的文本清理路径中删除 |
| `U+2060` | WORD JOINER，词连接符 | 在受支持的文本清理路径中删除 |
| `U+FEFF` | ZERO WIDTH NO-BREAK SPACE / BOM | 在受支持的文本清理路径中删除 |
| `U+00AD` | SOFT HYPHEN，软连字符 | 在受支持的文本清理路径中删除 |

这些字符可能来自正常排版或编码过程，存在并不能证明文档由 GPT 生成。删除后也可能改变换行行为。`--keep-invisibles` 可以关闭这四种字符的清理。

ZWJ、ZWNJ、变体选择符等其他字符可能影响文字塑形、语言拼写或 emoji 显示，因此不会被当作水印统一删除。报告中的字符提示应结合语言和文档上下文判断。

## 保留模式

DOCX 是包含多个 XML 部件和资源的文档包。保留模式在支持的 `w:t` 文本节点中执行字符清理，处理支持的 `docProps` 文档属性及 `rsid` 编辑会话标识，同时尽量保留其他部件和关系。

这一处理范围不等于对包中所有 XML、嵌入文件和二进制资源做匿名化审计。复杂部件可能包含额外文本或身份信息，仍需检查报告与原文。

PDF 的文字不一定以连续字符串保存。为了保留页面内容，PDF 保留模式只清理支持的元数据，不重写页面文本。因此它不会保证清除页面文字里的指定字符，也不会删除页面上的图片水印。

## 重建模式

重建模式把可抽取正文作为输入，经字符处理后写入新 DOCX、PDF 或文本文件。它接近“根据抽取文字重新输入”，会重新排版，不能承诺恢复原有图文结构。

图片、公式、批注、页眉页脚及其他复杂内容可能无法进入抽取正文。工具对已识别的有损风险默认拒绝继续，`--allow-lossy` 表示用户接受这些损失。复杂内容检查也不是对所有文件结构的完备证明，输出仍需要人工核对。

当前没有 OCR。对含无法抽取文字的扫描页的 PDF，重建会拒绝处理，而不会把图片中的内容当作已成功转录。

## 比较结果的含义

处理报告以原件抽取文字应用本次清理规则后的预期文本为基准；PDF 保留模式的预期文本保持原样。正文一致性检查忽略全部空白，并另列精确文本比较。忽略空白的比较有助于识别重排版后的正文序列变化，但可能忽略具有含义的空格；精确比较则可能因为重排版增加换行而不一致。

两种比较都基于工具能够抽取的文本，不能证明像素、分页、图像或公式一致。也不能判断统计文本水印是否存在。文件摘要用于将报告关联到具体文件，摘要不同只证明字节有变化。
